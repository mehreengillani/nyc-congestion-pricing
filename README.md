# Is Congestion Pricing Working? Manhattan Traffic After the Toll

A *Data with Mehreen* project analyzing the MTA's
[Congestion Relief Zone Vehicle Entries](https://data.ny.gov/d/t6yz-b64h) open data.

## Run it
```bash
pip install -r requirements.txt
```
Open `01_week1_explore.ipynb` in VS Code and click **Run All**.
The first run downloads the summarized data from the NY Open Data API (a minute or two)
and saves it to `data/`. Later runs load it from there.
